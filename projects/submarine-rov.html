ArduSub-Based Submarine ROV

ArduSub-based underwater ROV rebuild using BlueOS, QGroundControl, Raspberry Pi, and Pixhawk.

No cover image available

Overview

This project rebuilt and documented an underwater ROV system around an ArduSub control stack, with emphasis on restoring missing hardware and making the system understandable for continued development.

My Role

As a UAV Engineering Intern at Idea8, I identified missing hardware components, designed replacement parts, sourced suppliers, coordinated manufacturing, and documented the rebuilt system.

Technologies Used

  • ArduSub, BlueOS, and QGroundControl.
  • Raspberry Pi and Pixhawk flight controller.
  • Replacement part design and supplier coordination.

Challenges

The main challenge was rebuilding an incomplete system while tracking missing components, replacement part needs, and manufacturing constraints.

Results / Current Status

The ROV system was rebuilt and documented for continued development and testing.
